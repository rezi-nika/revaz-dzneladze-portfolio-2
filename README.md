# რევაზ ძნელაძე — React პორტფოლიო

თანამედროვე, სრულად რესპონსიული პორტფოლიო შექმნილი **React 18**, **Vite** და **Tailwind CSS**-ის გამოყენებით.

---

## 🚀 პროექტის გაშვება

```bash
# პაკეტების ინსტალაცია (თუ უკვე არ არის დაყენებული)
npm install

# დეველოპმენტ სერვერის გაშვება
npm run dev

# საწარმოო ვერსიის აწყობა (Production Build)
npm run build

# აწყობილი ვერსიის შემოწმება (Preview)
npm run preview
```

---

## 🧩 კომპონენტების სტრუქტურა

პროექტის მთავარი გვერდი დაყოფილია მოდულურ კომპონენტებად, ხოლო განმეორებადი ვიზუალური ელემენტები ჩანაცვლებულია მრავალჯერადად გამოყენებადი კომპონენტებით:

### 1. მრავალჯერადი საბაზისო UI კომპონენტები (`src/components/ui/`)
- **`Card.jsx`** — უნივერსალური ქარდის კომპონენტი Emerald Forest სტილის მინის ეფექტით (Glassmorphism), ჰოვერ განათებითა და საზღვრის ანიმაციით. გამოიყენება უნარებში, პროექტებში, გამოცდილებაში, თანამშრომლებსა და კონტაქტში.
- **`Badge.jsx`** — მრავალჯერადი თეგის / ბეიჯის კომპონენტი სხვადასხვა ფერის ვარიაციით (`brand`, `teal`, `emerald`, `amber`, `gray`, `outline`).
- **`Button.jsx`** — პოლიმორფული ღილაკი (`button` ან `a` ლინკი) ვარიანტებით (`primary`, `secondary`, `outline`, `ghost`), ჩატვირთვის სტატუსითა და აიქონებით.
- **`SectionHeader.jsx`** — სექციის უნიფიცირებული სათაური ზედა ბეიჯით, გრადიენტული ტექსტით, აღწერითა და დამატებითი მოქმედებების ღილაკებით.
- **`Modal.jsx`** — ხელმისაწვდომი მოდალური ფანჯარა ფონური დაბინდვით, `Escape` კლავიშისა და გარე დაკლიკების დეტექციით.

### 2. სპეციალიზებული ქარდები (`src/components/cards/`)
- **`SkillCard.jsx`** — ტექნოლოგიური უნარების ბარათი პროგრესის ინდიკატორებით.
- **`ProjectCard.jsx`** — პროექტის ბარათი CSS Mock UI ფანჯრის პრევიუთი, ტეგებითა და Live/Source ბმულებით.
- **`ExperienceCard.jsx`** — სამუშაო გამოცდილების ქარდი Timeline ინდიკატორითა და მიღწევების ჩამონათვალით.
- **`EmployeeCard.jsx`** — თანამშრომლის ბარათი გრადიენტული ავატარით, საკონტაქტო დეტალებითა და "დავალებების ნახვა" ფუნქციონალით.

### 3. მთავარი სექციები (`src/components/`)
- **`Navbar.jsx`** — ფიქსირებული ჰედერი ლოგოთი, დესკტოპ ნავიგაციით, თემის შეცვლითა და მობილური ანიმირებული ბურგერ მენიუთი.
- **`Hero.jsx`** — შესავალი სექცია, კიბერ-ტერმინალის მონოგრამით (`<RD />`), სტატუსის ინდიკატორითა და სწრაფი მოქმედებების ღილაკებით.
- **`Skills.jsx`** — უნარების ბადე 4 ძირითადი კატეგორიით (Frontend, Backend, Databases/DevOps, Tools).
- **`Projects.jsx`** — პროექტების კატალოგი ინტერაქტიული კატეგორიის ფილტრით.
- **`Experience.jsx`** — კარიერული განვითარების ქრონოლოგიური ხაზი.
- **`Employees.jsx`** — JSONPlaceholder API (`GET /users`) ინტეგრაცია, რეალურ დროში ძიება, სტატისტიკა და მოდალი (`GET /todos?userId={id}`).
- **`Contact.jsx`** — საკონტაქტო ბარათები და ინტერაქტიული შეტყობინების ფორმა ვალიდაციითა და წარმატების ინდიკატორით.
- **`Footer.jsx`** — საავტორო უფლებები, სოციალური ბმულები და ზევით დაბრუნების გლუვი სქროლი.

### 4. თემები & მონაცემები
- **`src/context/ThemeContext.jsx`** — Dark / Light რეჟიმის მართვა `localStorage` და `html.light` / `html.dark` კლასის სინქრონიზაციით.
- **`src/data/portfolioData.js`** — ცენტრალიზებული მონაცემთა ფაილი პორტფოლიოს ინფორმაციისთვის.
